# Report-reader evaluation — 2026-09-05

These are local observations from the 0.16/schema-17 overhaul. They do not
establish billed-token savings, production latency, or results for every project.
The existing-test trial can be rerun with `python3 evals/selected-test-trial.py`;
commands, reports, receipts, and logs are written under `target/evals/`.
The old server measurements require the earlier build and retained artifacts.

## Discovery payload

Serialized JSON-RPC bytes for the same requests on the same machine:

| Request | Old 0.15.5 | New 0.16.0 |
| --- | ---: | ---: |
| initialize | 4,359 | 1,532 |
| tools/list | 34,871 | 4,452 |
| Total | 39,230 | 5,984 |
| Advertised tools | 8 | 2 |

The discovery payload was 84.7% smaller. Client caching, hidden context, and
model behavior affect token usage, so this is a byte comparison only.
A historical replay also found 134 source-page calls returning 3,095,492 bytes;
fewer than 1% of its line records were gaps. That whole-file scan is a different
workload from a targeted query and cannot establish a savings percentage.

## Existing project trial

A targeted `FT_Stream_OpenBzip2` query against Fontdone's existing LLVM report
returned three groups/six missing regions in 1,515 bytes (1.263 seconds), with
source identity explicitly unverified. Reading an older saved snapshot over
MCP also succeeded and preserved its original 90,972 / 94,473 region totals.

The existing `make test-case CASE=ftbzip2.FT_Stream_OpenBzip2.error_callback_short_header_read`
command failed before the selected case because a shared fixture-cache entry
referenced an unknown manifest case. No fresh coverage gain was claimed and
no fixture checks were bypassed.

## Verification scope

At the time of evaluation, all workspace tests, 13 deterministic query outcomes,
75 marketplace checks, formatting, Clippy, rustdoc, and the bundled release build
passed. The configured library coverage gate measured 39,668 lines, 2,151
functions, and 15,037 regions, all covered; `src/main.rs` was excluded by policy.
HTTP and stdio advertised the same two-tool contract, and the dashboard was
exercised with gap and comparison results.

These are dated observations, not the current checkout's coverage totals.
No blinded model A/B test or clean-install test on every supported host was run.
